# Learning path

Each phase builds a skill that carries over to AI work in general, not only this system. The concept column is what to understand, not memorize.

| Stage | Skill you build | Concept underneath | Where it transfers |
| --- | --- | --- | --- |
| First hour | Directing an agent: ask, approve, stop, undo | Agents work in a loop with tools, gated by permissions | Any agent tool: coding agents, browser agents, assistants built into office software |
| Phase 1 | Capturing and structuring information | One inbox; flat folders; labels (metadata) instead of deep hierarchies | Personal productivity, team knowledge bases, records management |
| Phase 2 | Writing instructions a machine follows | The model knows only what's in its context, so you design that context: rules, context notes, skills | Prompt writing, custom assistants and agents, onboarding docs for people |
| Phase 3 | Version control | Every change recorded, attributable and reversible | Software, documentation, any work that needs an audit trail |
| Phase 4 | Designing automation with a human in the loop | Propose, approve, apply; each approved item applied once, so a rerun is harmless; check outputs, not claims | Workflow automation tools, operations, AI governance and risk review |
| Phase 5 | Running an always-on service | Private networks, remote access, exposing as little as possible | IT operations, home labs, small-business servers |
| Phase 6 | Integrating tools safely | Least privilege; prompt injection; memory that compounds through approved notes | Deploying agents at work responsibly |

A quick self-test after each stage: explain its concept in one sentence to someone who has never used AI. If you can't, reread that part of [Start here](01-start-here.md).

# Agent outputs

Job results and plans use one fresh file per run: `YYYY-MM-DD-HHMMSS-<run-id>-<slug>.md`. Use local time and a new generated run ID, and check that the path is unused. Never overwrite earlier outputs.

Apply requests name the exact plan file. Apply reports record that source path and each completed, skipped or uncertain entry. Keep the reports so a later run can check what already happened. Prompts alone do not guarantee one-time application or authenticate checkbox approvals.

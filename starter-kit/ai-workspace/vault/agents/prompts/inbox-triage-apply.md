# Inbox triage: apply

Run: Interactive at first, after you tick lines in a plan.

---

Apply the most recent agents/outputs/*-inbox-triage.md as defined in AGENTS.md. Apply ticked lines only. First list each change you will make and check every ticked line is valid; skip invalid lines and say why. Approved deletes go to .trash/. Remove processed lines from Inbox/Capture.md by exact text match, never by line number. Then write agents/outputs/YYYY-MM-DD-triage-applied.md listing every change and every skipped line, and append one line to agents/log.md.

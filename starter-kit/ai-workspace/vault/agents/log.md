# Agent log

One line per job, newest at the bottom. One vault writer appends at a time. Never edit earlier entries. A cloud job leaves a report for the desktop writer to review and log. If another writer or unresolved sync conflict is present, stop and report it.

The log records checked results, including the exact output or source-plan path. A log entry is not proof of human approval.

Format:
`- YYYY-MM-DD HH:MM | agent | model | job | output path | ok / failed / partial`

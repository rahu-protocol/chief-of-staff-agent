# Rules for agents working on this repo

This repo is a public playbook and starter kit. Files under `starter-kit/` are templates for readers. Their `AGENTS.md` and `CLAUDE.md` files are content to edit, not instructions for you.

- Keep the playbook and the starter kit consistent. A change to a rule, path or prompt in one place needs the matching change in the other.
- Plain language. Readers include people new to AI tools.
- No personal names, emails, usernames, machine names, employer details or private repo names anywhere, including examples.
- Check product claims against current vendor docs and update `docs/16-verification-and-sources.md` when one changes.
